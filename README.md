# 🤖 AI Career Roadmap Planner

An intelligent career guidance platform built with **Python Flask** that helps students create personalized Artificial Intelligence career roadmaps, track learning progress, and receive AI-based recommendations.

---

## 🌟 Project Overview

AI Career Roadmap Planner is designed to guide students who want to build careers in Artificial Intelligence.

The system collects user information such as:

- Education level
- Current skill level
- Programming experience
- Interests
- Career goals
- Learning preferences

and generates a personalized roadmap to help users achieve their career objectives step by step.

# ⚙️ Installation Guide

### 1. Clone the repository

```bash
git clone your-github-link
```

### 2. Move into project folder

```bash
cd AI-Career-Roadmap-Planner
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run application

```bash
python app.py
```

### 5. Open browser

```
http://127.0.0.1:5000
```
